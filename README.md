# 高中化学知识点题库

现行版本已完成2431道整题、9个批次的全量分包重构。

## 使用

Windows本机双击“更新题库.cmd”，会启动或复用本机阅读服务并打开首页。不需要联网。已启动时“题库首页.html”会自动进入新版；未启动时提示使用更新入口。新结构不支持直接离线读取二进制包。

- `02_设定层/题库阅读版/`：独立静态阅读版，全部题干、图像、MathML公式、表格、原答案解析和来源。
- `02_设定层/题库维护/`：构建、监测服务、完整性校验及全量报告。
- `02_设定层/试卷分类题库/批次记录/`：原分类记录、来源和完整性证据。

资料层的原教材和原试卷不在本仓库，保存在本地。其文件链接仍需要本机原资料。云端只需部署“题库阅读版”目录并使用HTTPS；建议支持Range。当前没有发布公开网站。

## 核验与维护

运行根目录 `python verify_snapshot.py` 核对现行全部阅读文件、图片字节与完整原HTML的逐字还原。维护说明和全量核验报告在题库维护目录。常规重建只写变化的包；分类监测只处理已分类数据，不自动提取原卷。

## 原版完整备份

`baseline-20261027`标签保留重构前完整题库，`pilot/packed-reader-180`分支保留试验结果。旧版HTML和独立图片已经从当前目录合并为资源包，原内容可逐字节恢复。`backup-manifest.json`和`backup-audit.json`属于旧基线证据，应配合基线版本查看。

本机另有 `D:\高中化学_本地备份\题库重构前-20261027.zip` 及逐文件校验清单。恢复时先解压或检出到新目录，不覆盖现行题库。Windows长路径恢复可使用 `git -c core.longpaths=true clone https://github.com/justlaughing/high-school-chemistry.git`，并在仓库内设置 `git config core.longpaths true`。
