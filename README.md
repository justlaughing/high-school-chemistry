# 高中化学知识点题库

本仓库先保存分块重构前的完整可恢复版本，再在独立分支验证新的数据组织方式。仓库为私有。

## 当前基线

- `题库首页.html`：离线浏览入口，使用相对路径加载同一套题库。
- `更新题库.cmd`：有 Python 时重建分类索引并启动本机实时服务。
- `02_设定层/试卷分类题库/`：分类记录、全部整题、图片、入口和工具。
- `backup-manifest.json`：逐文件 SHA-256、文件数、体积与备份范围。

原始教材和原试卷不在此次 GitHub 备份范围内，仍保存在本地资料层。因此原题页面中指向原始 Word/PDF 的链接需要相应本地文件；已提取的题干、图片、公式、答案和解析均在仓库中。

本机运行状态、日志、缓存和历史入口备份不作为版本内容保存。实时地址在启动服务时重新生成。

## 恢复

1. 下载或检出所需的基线版本，保持目录结构。
2. 使用 `python verify_snapshot.py` 核对备份文件。
3. 双击 `题库首页.html` 离线浏览；需要实时服务时运行更新入口。

分块重构先使用独立输出目录试验，不覆盖当前正式入口。
