# 全量分包题库维护

原教材、原试卷保存在资料层，只读。日常使用根目录“更新题库.cmd”，检查已入库分类、启动或复用本机服务并打开首页。服务只监听127.0.0.1，无需联网，不自动上传。

## 文件职责

- `../试卷分类题库/批次记录/各批次/分类数据.json`：分类和来源依据。保留原批次编号、题号及分类记录。
- `../题库阅读版/questions/`：完整正文，按“批次SHA-256前12位＋题号SHA-256首位”固定分包。
- `../题库阅读版/assets/`：原始图片字节按SHA-256去重，首两位固定分成256组。
- `../题库阅读版/asset-index.json`：图片偏移、长度、格式；工具和浏览器核对图片字节哈希。
- `../题库阅读版/styles.json`：原题共享样式。正文包保存能逐字还原的HTML、图片原路径映射和原字节哈希。
- `../题库阅读版/manifest.json`：发布清单，最后更新；输入不完整时保留上次完整题库。
- `content-index.json`：稳定题号和正文包关系，保留旧HTML路径作来源记录。分类文件的旧路径不再要求有同名HTML。
- `web/`、构建/服务/校验工具、报告和`qa/`：本地维护内容，不混入云端阅读目录。

旧HTML和独立图片已压入本地完整存档，GitHub的`baseline-20261027`保留原版。恢复时先解压到新目录核验，不覆盖当前题库。历史分类报告、来源清单及完整性记录继续保留。

## 更新与导入

修改分类时保持“批次＋id”不变，保留主类别、相关类别和小问结构。运行`build.py`，或由本机服务检测分类变化。无变化不重写产物；正文变化只重写对应内容包；图片变化只影响有关资源包及索引。页面出现新版提示后刷新读取。

新增原卷须先提取、分类。新题应先生成包含完整题干、原图、公式、原答案和解析的临时HTML，让`relative_path`指向题库内该文件，再保存分类数据并构建。校验成功前不能移走临时文件；成功后可将导入HTML及原图另行归档。正常重建从数据包读取已入库正文，不依赖历史HTML。不要手改图片偏移或正文哈希。

内容保留原题与原解析，未重新分类或解题。云端只复制“题库阅读版”，以HTTPS访问；建议支持HTTP Range，否则回退整包读取。较早图片及整包缓存会回收。双击HTML无法直接读取二进制包，请使用根目录更新入口；本机服务不需要互联网。

## 核验

`python verify.py`核对全部发布文件、图片切片及原HTML的逐字还原。`python verify.py --incremental`额外验证不变重建、单题正文和分类标题变化的影响，临时改动随后恢复。

`python serve.py --qa --no-watch --port 8796`提供核验页。原HTML对照仅在保留旧工作副本时使用。正常服务不暴露维护目录或资料层。本机日志及状态不放入Git。

已打开页面在重建后可能提示刷新。云端应整版部署切换，避免边复制边公开不完整目录。
